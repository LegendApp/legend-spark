# Spark app

Run the app with `windows` using your chosen package manager:

```sh
npm run windows
```

macOS opens in Spark Runner. Windows requires a custom development build and is
an unverified preview. JavaScript edits use Fast Refresh. Use `npm run build` for
a standalone macOS app; native builds require Xcode and CocoaPods.

Use the equivalent `bun run`, `pnpm run`, or `yarn` commands for those managers.
See [Spark documentation](https://legend.so/spark) for configuration, upgrades,
platform prerequisites, and distribution.
