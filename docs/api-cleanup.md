# API cleanup implementation

Approved scope: [shared contracts and all API families](api-contracts.md), including the [window contract](api-window-contract.md). React Native is assumed; no legacy/deprecated forwarding exports are required. Expo compatibility applies to explicitly selected methods; SQLite and WebView require Spark-owned contracts.

Base: `5e17417` on `jmeistrich/fix-api-defects`. Local stack starts at `jmeistrich/api-contracts`. Remote main has unrelated divergence; no history rewrite or push is part of this work.

## Completion criteria

- [ ] Shared errors, native-response validation and lifecycle contracts used by feature APIs.
- [ ] App/documents/windows consolidated, with explicit identities, typed events and preserved desktop capabilities.
- [ ] Menus, shortcuts, context/tray/Dock share contracts.
- [ ] Files/dialogs/settings and remaining system APIs normalized; duplicate public exports removed with their callers.
- [ ] SQLite, WebView and audio expose owned contracts, with adapter/lifecycle coverage.
- [ ] UI, drag/drop and configuration/tooling contracts aligned.
- [ ] Public export inventory reconciled, TypeScript and relevant tests pass; native checks recorded with actual target coverage.

This is an implementation checklist, not a claim that the whole approved design has landed. Unit checks with mocked native boundaries do not establish native platform parity.

## Verified units

- Shared native-free contracts: 8 focused tests and full TypeScript check passed.
- SQLite: public backend objects replaced by Spark query/transaction/close types; kitchen-sink callers updated. Real in-memory SQLite tests cover parameters/blobs, commit/rollback, transaction lifetime, close ordering and unsafe values. Native OP-SQLite execution still requires target validation.
- WebView: owned component/source/ref/event types replace upstream reexports; kitchen-sink uses plain Spark event payloads. Adapter tests cover source/event translation, unknown backend props and stale refs. Native navigation/message execution remains to be validated.

- Dialogs: one `/dialogs` export; explicit open/save cancellation and stable message button IDs. File IO moved to `/files` (`writeTextIfUnchanged` and `revealInFileManager` included); old names and `/message-dialog` removed with repository callers. Missing modules import safely, unsupported hosts reject, malformed output rejects. File filters are extension-only and combined; mixed selection is a macOS option. Open/save owner-window targeting is not yet implemented; unknown options reject. The following file-IO unit moves reveal/conditional writes into the filesystem native module, removing its dialog dependency. Conditional writes detect observed edits, not an OS-wide atomic compare-and-swap. Full TypeScript and 85 focused/API/codegen tests pass. Native UI validation is pending.

- File IO: `readBytes`/`writeBytes`, `FileInfo`, named/path directory entries and void/idempotent removal replace old transport/results. Local file URLs normalize to native paths; result shapes, numeric bounds and binary responses are checked. Watch removal/file close join concurrent cleanup and can retry failures. The native file module now owns conditional write/reveal and the old dialog native methods are deleted. macOS deletion distinguishes permissions from absence and removes dangling links. Full TypeScript and 89 focused/API/codegen/native-mutation tests pass; the Foundation test executes the actual macOS conditional-write/removal implementation. Full RN host integration and Windows native compilation remain pending. Scanner and specialized watcher consolidation is the next file unit.

- Scanning/watching: `scanFiles` and owned types are exported with `/files`; `/files/scanner`, `/files/watchers`, the raw scanner emitter and the singleton watcher module are removed. Native scan IDs correlate concurrent calls; per-call callbacks and cooperative AbortSignal cancellation clean up before completion. Document reload uses the ordinary invalidation watcher, reports errors and disposes late registrations. Full TypeScript and 80 focused/API/codegen/scanner tests pass. Scanner core runs against real files in a Foundation test; native RN event transport still needs host validation.

- Expo subsets: remove clipboard text aliases and the `secureStorage` facade; the unused synchronous service-keychain API and its native entry are deleted. Shared Clipboard types are owned by Spark on desktop and Expo adapters. Rich PNG content uses bytes; write inputs distinguish file lists from text/images while reads preserve coexisting OS representations. Secure storage and clipboard import without native modules and validate added options/native output. Full TypeScript and 86 focused API/codegen/availability tests pass. Native Keychain/clipboard execution and mobile device acceptance remain pending.

- Settings store: explicit `{ storage }` factory, named interfaces, missing=`undefined` vs stored `null`, and decoder-backed typed reads. Invalid JSON values (including Date/Map/Set coercion and sparse arrays) reject; queued sets snapshot input. Per-key serialization recovers after errors and remains local to each store. TypeScript and ten settings tests pass. Observable persistence and raw storage consolidation follow in a separate unit.

- Observable settings: awaited loading with required decoding, one `value$`/`error$`/`flush`/`close` handle, snapshot writes and retryable cleanup. The shared async file backend replaces synchronous native storage and `/settings/paths`; generic raw storage helpers are deleted in favor of `/files`. Field defaults distinguish absent and null; Legend State owns observable/React APIs. Full TypeScript and 105 focused API/settings/codegen/metadata tests pass, including corruption, batching, debounce, async encoding, failure and lifecycle coverage. Native file transport retains its separate host-validation requirement.

- Updates: one functional API, explicit check mode and configuration, void command results, typed status/unavailability and shared errors. The native adapter validates configuration before starting; the event transport now loads lazily for optional features. Removed AutoUpdater and redundant setters, updated examples and the standalone probe. TypeScript and 87 focused API/availability/codegen/update tests pass. Sparkle execution in a signed standalone Release host remains pending.

- Notifications: owned content and delay-trigger types, immediate/scheduled submission split, permission status plus prompting capability, separate pending cancellation and delivered dismissal. Options/native responses are checked; subscription replay validates payloads and cleans up on failure. Updated macOS/Windows adapters, examples and docs. Full TypeScript and 87 focused API/availability/codegen tests pass. OS presentation, permissions, response activation and Windows native compilation remain pending.

- Audio player: shared command ordering, async argument failures, validated status/results, retryable cleanup, configurable readiness timeout and load cancellation across desktop/mobile/browser adapters. The React hook exposes loading/ready/error and owns late-player disposal; metadata can be cleared explicitly. Native removal is idempotent. Full TypeScript and 41 focused player/adapter/media/codegen tests pass. Hook mount/unmount renderer tests and actual native playback remain pending; independent media-session cleanup follows separately.

- Independent media sessions: creation-owned callbacks, discriminated seek commands, explicit metadata clearing, ordered replacement/update/disposal, stopped stale callbacks and retryable native removal. Unsupported mobile sessions reject with a shared code. TypeScript and 46 focused player/media/adapter/codegen tests pass. OS command routing and native control presentation remain pending.

- Shortcuts: one accelerator parser, validated registration/options/results, safe availability, immediate callback stop and shared retryable cleanup. Removed the unused singleton numeric hotkey facade. Windows local shortcuts now reject scope conflicts and prefer a window binding over an app binding; native global unregistration checks errors before forgetting ownership. Full TypeScript and 95 focused API/availability/accelerator/codegen tests pass. Real OS registration/key dispatch and Windows compilation remain pending.

- Shared menus/context menus: discriminated items with stable IDs, labels, flags, validated accelerator/icon/slider options, and per-surface capability checks. Context menus require an explicit owner and logical content position, return discriminated cancellation, and reject unknown/disabled selections. Updated both native owner lookups and repository callers. Full TypeScript and 96 focused menu/API/availability/codegen/metadata tests pass. Native popup placement/selection acceptance remains pending; application, tray, Dock and toolbar adapters follow.

- Tray: shared menu items, creation-owned callbacks, named update/handle types, explicit macOS symbol options, immutable IDs, snapshot/ordered updates and retryable removal. Duplicate creation leaves the existing item intact. Windows deletion failures preserve native ownership for retry. Full TypeScript and 100 focused menu/API/availability/codegen/metadata tests pass. Actual status-bar/taskbar presentation and Windows compilation remain pending.

- System: named attention/power options, validated query results, shared errors and retryable registrations. Independent native event subscriptions release OS observers after the last removal. App badges have a platform-neutral name; explicit Dock/taskbar menu creation reuses shared items and owned callbacks. Native sleep cleanup retains macOS assertions on failure and closes dedicated Windows power handles. Full TypeScript and 105 focused tests pass; the actual macOS implementation passes an Objective-C++ syntax check with bridge declarations stubbed. Native behavior and Windows compilation remain pending.

- Application menus: owned create/update/remove plus `useMenu`, shared items/accelerators, semantic role/ID targets and placement, acknowledged serialized native publication and restoration of earlier owners. Removed translated-title targeting, raw bridge/global listeners and the unused numeric menu-shortcut converter. Full TypeScript, explicit changed-template TypeScript and 119 focused tests pass, including mounted React Strict Mode/late-cleanup tests and the actual AppKit implementation against native menus. Interactive native accelerator dispatch and Windows compilation remain pending.

- Links/documents: selected Expo link methods retain their semantics, with a separate desktop `openPath` extension. Recent history and discriminated file/URL requests now live under `/app/documents`; file paths decode once, native results validate, and replay/live overlap deduplicates during busy delivery. Removed `/app/recent-documents` and its duplicate native emitter while preserving the native controller startup plugin. Document request/history imports no longer load managed-window APIs eagerly. Full TypeScript, changed-template TypeScript and 115 focused tests pass; both changed macOS implementations pass C++20 syntax checks with bridge declarations stubbed. OS association launches, recent-history UI and Windows compilation remain pending.

- Authentication: validated owned inputs/crypto/native responses, shared errors, preparation-inclusive timeout and retryable cleanup that retains session ownership after failure. Failed creation preserves cleanup for the next attempt. Android owns its callback observers so cancellation releases them immediately; popup completion has the same selected Expo result shape on every platform. TypeScript and 129 focused tests pass, including desktop/mobile transport and cancellation coverage. The standalone C++ loopback protocol/socket test also passes. Real OS browser launches, mobile device behavior and Windows compilation remain pending.

- Processes: one target/options/handle/result contract replaces the separate command-runner facade. Byte streams and binary stdin, configurable capture limits, host PATH lookup on both desktops, AbortSignal cancellation, ordered writes and retryable termination waiting for drained exit. Removed `/processes/commands`, updated sidecar consumers, and fixed inherited macOS signal state that prevented cooperative termination. Full TypeScript and 143 focused API/codegen/helper tests pass. A separate test executes the actual macOS process implementation for binary IO, capture limits, nonzero exit, timeout, SIGTERM and descendant cleanup. Full RN-host integration and Windows compilation/acceptance remain pending.

- Commands/keyboard: named accelerator syntax, one array binding format, strict versioned persistence and consolidated lazy `createHotkeyStore`. Removed numeric/display/legacy conversion, the scalar hook/settings duplicates, raw keyboard exports and `/shortcuts/commands/storage`. Async keyboard registration owns native monitoring and retryable cleanup; router hooks read current callbacks and dispose late registrations, and capture listens only while active. The macOS event adapter reports layout-derived keys and normalized window IDs, and drops late native responses. Full TypeScript and 142 focused tests pass, including mounted React hooks/capture, persistence, routing and observer cleanup; native keyboard source passes a C++20 syntax check with bridge declarations stubbed. Actual native key dispatch/layout/focus acceptance remains pending; the low-level backend and command router explicitly reject unsupported Windows/mobile hosts.

- Application lifecycle: validated identity/runtime context, typed live listeners and one awaited quit result. Independent quit guards share the native all-handler decision, reject stale completions, stop callbacks on removal and retry failed cleanup; removed `/app/exit` and the duplicate native module. Windows now separates quit and window-close timers. Full TypeScript and focused API/codegen/lifecycle/metadata tests pass; the actual macOS coordinator fixture covers decision observers and deadlines, and the changed bridge/transport passes a C++20 syntax check with RN declarations stubbed. Actual host shutdown and Windows compilation remain pending. See [application lifecycle](app.md).

- Drag/drop: one generic component with named owned payload/event types, shared validation/errors, normalized file sources, safe availability and application-controlled error UI. Full TypeScript and focused contracts, mounted React, codegen and metadata tests pass. Actual native dragging and Windows compilation remain pending; see [drag/drop](drag-drop.md).
